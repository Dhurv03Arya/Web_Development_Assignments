Technical Notes & Fan Profile API

Advanced users can adjust system power limits and thermal limits using our CLI utility. Power targets can be toggled between Silent (45W), Balanced (95W), and Turbo (175W).

Below is a sample JSON payload used by the Apex Control Center daemon to trigger Turbo mode programmatically:


{
  "system_profile": "TURBO_PERFORMANCE",
  "power_limits": {
    "PL1_watts": 115,
    "PL2_watts": 175,
    "time_window_seconds": 28
  },
  "fan_curve": {
    "cpu_target_temp_celsius": 85,
    "gpu_target_temp_celsius": 78,
    "minimum_rpm": 3200
  },
  "overclock": {
    "gpu_core_offset_mhz": +150,
    "vram_clock_offset_mhz": +300
  }
}

Glossary of Technical Terminology

RAM (Random Access Memory)
High-speed volatile system memory used by the operating system and applications to store active execution data for near-instantaneous access.
SSD (Solid State Drive)
Non-volatile flash storage utilizing PCIe NVMe protocols to achieve rapid read/write speeds exceeding 7,000 MB/s.
Refresh Rate
The frequency with which the display panel updates its image per second, measured in Hertz (Hz). Higher refresh rates yield smoother motion rendering.
Warranty
A manufacturer-backed guarantee covering repair or replacement of hardware components against defects in materials and workmanship.

Purchase & Unboxing Setup Steps

  1. Unpack the Apex Pro Ultra 16 and verify all included accessories (330W GaN Adapter, Power Cable, Welcome Manual).

  3. Power on the device and complete the Windows 11 initial setup wizard.
  4. Launch the Apex Control Center to download the latest GPU drivers and firmware updates.
